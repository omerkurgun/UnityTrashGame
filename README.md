# 🗑️ Trash Game

Çöp toplama oyunu - Unity

## 📝 Açıklama

Trash Game, Unity ile geliştirilmiş eğlenceli bir çöp toplama oyunudur. Oyuncular çevredeki çöpleri toplayarak puan kazanır.

## 🎮 Nasıl Oynanır

### Amaç
Sahneye dağılmış 20 çöpü toplayıp çöp kutusuna atmak ve zamanın bitmeden oyunu tamamlamak!

### Kontroller
- **Yön Tuşları (WASD / Arrow Keys)**: Karakteri hareket ettir
- **Mouse**: Kamerayı döndür ve çöpleri hedefle
- **Mouse Sol Tık**: Fırça ile çöp al/bırak

### Oyun Mekanikleri
- ⏱️ **100 saniye** süren var
- 🗑️ Sahneye dağılmış **20 çöp** toplamalısın
- 🖌️ Fırça ile çöpleri **tek tek** al
- 🎯 Toplanan çöpleri **çöp kutusuna** bırak

### Hayvanlar
- 🐱 **Kedilere** dokunursan: **+10 saniye** bonus kazanırsın
- 🐕 **Köpeklere** dokunursan: **-10 saniye** ceza alırsın
- 🔄 Herhangi bir hayvana dokunduğunda **sahnenin ortasına** ışınlanırsın
